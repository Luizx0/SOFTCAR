🚗 SOFTCAR — Loja de Carros, Peças e Acessórios

Projeto acadêmico de desenvolvimento de um site para a SOFTCAR, uma loja fictícia especializada na venda de carros, peças e acessórios automotivos.

O projeto foi desenvolvido com HTML, CSS e JavaScript, aplicando conceitos de estruturação de páginas, formatação de textos, navegação, tabelas, listas, imagens, links externos, âncoras, wireframes e automação de eventos.

🎯 Objetivo

O objetivo principal é desenvolver um site completo para uma loja de carros, peças e acessórios, colocando em prática os conhecimentos adquiridos durante as aulas de desenvolvimento web.

O projeto também busca trabalhar criatividade, organização de conteúdo, usabilidade e apresentação visual.

🏢 Empresa — Briefing

A seção Empresa possui uma página contendo o briefing completo da SOFTCAR.

As 17 perguntas e respostas do briefing ficam disponíveis em uma página HTML que pode ser acessada diretamente pelo menu do site.

O briefing apresenta informações sobre a empresa, público-alvo, objetivos, identidade visual, produtos, concorrência e demais características necessárias para o planejamento do site.
